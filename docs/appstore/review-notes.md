# Notes for App Review

Paste into App Store Connect → App Review Information → Notes.

---

BoxPilot is a Wi-Fi remote control for Infomir MAG set-top boxes. It needs a MAG box on the same local network to control real hardware.

**Testing without a MAG box:** after the short setup guide, tap "Try free for 1 day" (sandbox, no charge). Then, on the Devices screen, tap "Try a demo box". This opens the full remote against a simulated box, so every screen and control can be reviewed: D-pad, keys, number pad, Type on TV, Touchpad tab, macros and quick actions.

**Local Network permission:** used only to find and control MAG boxes on the user's Wi-Fi. The app does not contact any server.

**In-app purchases:**
- `com.iptvmkremote.trial` "1-day Trial": a free non-consumable that starts a 24-hour trial, following guideline 3.1.1 for free trials of paid functionality.
- `com.iptvmkremote.unlock` "Unlock BoxPilot": a one-time, non-consumable purchase that unlocks the app permanently.
The paywall states the trial length and that nothing is charged or renewed. "Restore purchases" is on the paywall and in Settings.

**Trademarks:** BoxPilot is an independent app and says so in its description and in Settings. "MAG" is used only to describe compatibility.
