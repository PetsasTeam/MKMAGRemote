# BoxPilot Support

BoxPilot is a remote control for Infomir MAG set-top boxes, over your home Wi-Fi.

## Getting connected

1. On the box, open **Settings → System settings → Remote control** and switch on **Use remote control**. If a password is set there, you'll need it.
2. Keep your iPhone on the **same Wi-Fi** as the box.
3. Open BoxPilot and tap **Find boxes**. When iPhone asks to find devices on your local network, tap **Allow**.
4. Tap your box. Depending on the box, enter its Remote control password, or the 6-digit code shown on the TV.

## If no box is found

- Make sure the box is on (not in deep standby) and on the same Wi-Fi network.
- Check **Settings → Privacy & Security → Local Network → BoxPilot** is on.
- Some routers keep devices apart ("AP isolation" or a guest network). Use the main network.
- Try **Enter IP address**. Find the box's address under **Settings → System settings → Network**.

## Typing on the TV

Select a text field on the TV first (for example, a search box), then tap the keyboard button in BoxPilot. Letters appear on the TV as you type.

## Touchpad

On boxes that use a password to connect, the Remote screen has a **Touchpad** tab: drag to move the pointer, tap to click, two fingers to scroll.
